# Brand Voice — Creator OS

---

## 1. En una frase

> Creator OS habla como un colaborador creativo claro y directo: propone opciones, quita peso y respeta tu criterio — nunca como un coach motivacional ni como un robot corporativo.

---

## 2. Personalidad (3 rasgos)

| Rasgo | Significa | En la práctica |
|---|---|---|
| **Claro** | Pocas palabras, una acción obvia | Botones y frases que se entienden a la primera |
| **Útil** | Cada mensaje empuja el loop idea → grabable | Cero relleno, cero “¡tú puedes!” vacío |
| **Respetuoso** | Tú decides el ángulo | Propone 3 caminos; no impone “la mejor opción” |

### Lo que no es

- Coach de Instagram / hype / emojis de fuego
- Asistente corporativo (“¡Hola! Estoy aquí para asistirte…”)
- Genius condescendiente (“Déjame pensarlo por ti”)
- App de productividad fría (“Task created successfully”)

---

## 3. Principios de copy

1. **Acción > decoración** — Si no ayuda a capturar, elegir, editar o marcar listo, sobra.
2. **Tú + la idea** — El sujeto eres tú y tu pieza, no “nuestra plataforma”.
3. **Proponer con humildad** — “Tres enfoques” no “el guion perfecto”.
4. **Español natural** — Cercano, sin jerga de startups ni anglicismos innecesarios. (Si el producto es bilingüe después, misma personalidad.)
5. **Sin teatro** — Nada de rankings, rachas dramáticas ni comparaciones con “otros creadores” en v1.

---

## 4. Vocabulario preferido vs evitar

| Preferir | Evitar |
|---|---|
| Idea, dirección, enfoque, borrador, guía, listo para grabar | Task, proyecto, pipeline, workflow, dashboard |
| Capturar, elegir, ajustar, continuar | Optimizar, maximizar, potenciar tu marca |
| Tres enfoques / tres direcciones | “Contenido viral garantizado” |
| Editar / personalizar | “Generar magia con IA” |
| Compañero / asistente (con cuidado) | Coach, guru, sistema operativo (en UI) |

> “Creator OS” puede ser el nombre del producto; en la UI preferimos lenguaje humano del loop, no “abrir el OS”.

---

## 5. Copy de momentos clave (v1)

### Onboarding — contexto (primera vez)

- Título: *“¿De qué va tu contenido?”*
- Sub: *“Así los enfoques y guiones se acercan a tu estilo — no a un genérico.”*
- CTA: *“Continuar”*
- Placeholder “Otro”: *“Ej. Roblox — guías y showcases de Anime Fighting Simulator”*
- Perfil después: *“Mi contenido”* → *“Puedes cambiar esto cuando quieras.”*

*(Usuario 1 de referencia: gaming / Roblox / AFS — guías, showcases, opiniones.)*

### Home

- Primario: **Capturar idea**
- Sección: **Continuar**
- Sección: **Listas para grabar**
- Sección: **Capturadas**
- Vacío (sin ideas): *“Cuando se te ocurra algo, captúralo aquí. Luego lo convertimos en algo grabable.”*

### Captura

- Placeholder: *“¿Qué se te ocurrió? No hace falta que esté claro.”*
- Confirmación: *“Idea capturada.”* (no confeti)

### Tres direcciones

- Título: *“Tres enfoques para esta idea”*
- Sub: *“Elige el que más suene a lo que quieres grabar.”*
- CTA: *“Usar este enfoque”*
- Ajuste: *“¿Algún ajuste antes del borrador?”*  
  Placeholder: *“Ej. más directo, menos técnico…”*
- Si falla la generación: *“No pude armar buenos enfoques. Intenta de nuevo o edita la idea.”*

### Borrador

- Título según formato: *“Guion”* / *“Guía para grabar”* / *“Guion + guía”*
- CTA estado: *“Marcar lista para grabar”*
- Volver a editar: *“Seguir editando”*
- Regenerar (si existe): *“Probar otro borrador”* — nunca *“Mejorar con IA”* como promesa mágica

### Lista para grabar

- Confirmación: *“Lista para grabar. Cuando quieras, abre esto y graba.”*
- En home, chip/estado: **Lista para grabar**

### Archivar

- *“Archivar idea”* / confirmación: *“Idea archivada. Puedes restaurarla después.”*

## 6. Cómo habla la IA dentro del producto

Cuando genera direcciones o borradores:

- Tono y referencias alineados al **contexto del creador** (nicho / “mi contenido”)
- Sin caer en clichés torpes del nicho (“bro” forzado en fitness, etc.)
- Sin relleno tipo “¡Claro! Aquí tienes un guion increíble…”
- Empieza por el contenido útil (nombre del enfoque, hook, beats)
- Si investigó algo ligero: mostrar el dato con modestia, no como verdad absoluta

**Micro-prefijos útiles (opcionales, discretos):**
- *“Enfoque 1 — …”*
- *“Hook: …”*
- *“Beat 1 — …”*

**Prohibido en outputs de IA:**
- “Como modelo de lenguaje…”
- “¡Por supuesto!”
- Promesas de viralidad
- Párrafos de introducción antes del contenido

---

## 7. Prueba rápida de tono

Lee cualquier string de UI y pregunta:

1. ¿Suena a compañero claro o a coach?
2. ¿Empuja idea → listo para grabar?
3. ¿Respeta que el usuario decide?

Si falla una, reescribir.
