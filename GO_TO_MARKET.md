# Go-to-market — Ideazo (público)

**Canal:** Web / PWA  
**Oferta:** Free (15 gen/mes) + Pro ($14/mes · $119/año)

## Antes de abrir

1. Checklist Usuario 1 en verde (`/profile/validacion` + `VALIDATION_USER1.md`)
2. Soft launch 5–10 creadores sin incendios (`INVITE_ONLY=true`)
3. Stripe live + webhook OK + 1 compra de prueba real
4. Dominio custom + `/terms` `/privacy` revisados
5. `INVITE_ONLY=false` (o waitlist selectiva)

## Distribución (orden)

1. **Tu audiencia** — un Short/TikTok mostrando idea → 3 enfoques → lista para grabar (demo real, no vapor).
2. **DMs a creadores short-form** amigos / nicho gaming — invite personal.
3. **Comunidades** (Discord/X) con el wedge claro: no “otra IA”, sino *lista para grabar*.
4. **Product Hunt / directorios** solo cuando Free→Pro convierta en soft launch.

## Métricas a mirar (no vanidad)

- Signup → onboarding completo
- Idea capturada → % lista para grabar
- Hit limit → click upgrade → checkout success
- Objetivo 30–60 días: **10 Pro** o evidencia clara de willingness-to-pay
