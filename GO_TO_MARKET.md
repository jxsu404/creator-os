# Go-to-market — Ideazo (público)

**Canal:** Web / PWA  
**Oferta:** Free (15 gen/mes) + donaciones PayPal (sin suscripción)

## Antes de abrir

1. Checklist Usuario 1 en verde (`VALIDATION_USER1.md` / `LAUNCH.md`)
2. Soft launch 5–10 creadores sin incendios (`INVITE_ONLY=true`)
3. Link PayPal OK en `/pricing` + 1 donación de prueba
4. Dominio custom + `/terms` `/privacy` revisados
5. `INVITE_ONLY=false` (o waitlist selectiva)

## Distribución (orden)

1. **Tu audiencia** — un Short/TikTok mostrando idea → 3 enfoques → lista para grabar (demo real, no vapor).
2. **DMs a creadores short-form** amigos / nicho gaming — invite personal.
3. **Comunidades** (Discord/X) con el wedge claro: no “otra IA”, sino *lista para grabar*.
4. **Product Hunt / directorios** solo cuando Free→donación muestre señal en soft launch.

## Mensaje

De idea a listo para grabar: 3 enfoques distintos + guía hablada. Gratis para probar; si te sirve, dona por PayPal.
