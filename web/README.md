# Creator OS — app (provisional)

Compañero creativo: idea → 3 enfoques → guía/guion listo para grabar.

## Setup

```bash
cd web
npm install
cp .env.example .env.local
# Edita .env.local → GEMINI_API_KEY (gratis: https://aistudio.google.com/apikey)
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Datos del dogfooding se guardan en **localStorage** del navegador.
